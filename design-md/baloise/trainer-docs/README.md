      --print-to-pdf=EN_Trainer-Guide_AI-Week_092026.pdf \
      file://$PWD/trainer_guide.html

`house.css` trägt dieselbe Gestaltung wie die Decks: Arial, Helvetia-Blau
`#000D6E`, Mint `#CBF2EC` für die Empfehlung, Rot-Tint `#FFD7D7` für die
Grenze, Hellgrau `#F6F6F6` für normale Information. 4 px Ecken, keine
Konturen, keine Grossbuchstaben-Labels, kein Grau für Text.

Agenda-Zeiten sind aus den Decks abgeleitet, nicht erfunden: die fixen
Blöcke (Umfragen, Übungen, Pause, Clinic, Q&A, Transfer) stehen als Badges
auf den Folien, der Rest ist auf 120 Minuten verteilt.
