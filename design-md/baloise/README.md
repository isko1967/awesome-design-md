# Baloise / Helvetia Design System — Extraktion für Folien

Extrahiert aus dem offiziellen Repository
[`baloise/design-system`](https://github.com/baloise/design-system) (Tokens + Foundation-Doku).
Im Gegensatz zu den übrigen Einträgen in diesem Repo stammt diese Extraktion nicht aus
einer Website-Analyse, sondern direkt aus der Quelle der Wahrheit — den Design-Tokens.

## Dateien

| Datei | Inhalt |
|---|---|
| `DESIGN.md` | Design System: Gestaltungspersönlichkeit, Farben, Typografie, Raster, Spacing, Radius, Elevation, Iconografie, verbindliche Regeln |
| `POWERPOINT-SLIDE-SYSTEM.md` | Übersetzung in ein 960×540-pt-Foliensystem, Archetypen, Prinzipien aus think-cell/Beratungspraxis, Vorgehensplan Block 1 |

## Hinweis

Das Repository befindet sich in der Umbenennung von *Baloise Design System* zu
*Helvetia Design System*. Tokens und Schriftnamen tragen weiterhin die Baloise-Bezeichnungen.
Schriften und Logos sind Corporate Assets und nicht Teil der Apache-2.0-Lizenz des Codes.
